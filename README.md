# 安燃桌宠

安燃是一个活泼可爱的 Kimi 原生 DIY 桌宠。本仓库是完整、独立的 Kimi 插件，包含技能、图集、桌宠清单和交互页面，不需要另装 `pet-plus`。

## 一句话安装并启动

在 Kimi Work 中对 Agent 说：

> 安装并启动这个 GitHub 仓库里的安燃桌宠：https://github.com/yuchangxu1989-Openclaw/anran-pet

Agent 应连续完成以下事项，不把中间步骤交还给用户：

1. 识别并导入本仓库，通过官方支持的入口安装插件。
2. 读取插件内的 `skills/anran-pet/SKILL.md`，执行完整安装流程。
3. 调用官方 `Widget.installPet` 创建独立安燃，发布随插件提供的交互页面并读回校验。
4. 报告插件安装、桌宠创建和页面发布三项结果；任何一项失败都明确说明，不把部分成功写成全部完成。

如果宿主提示插件需要重启才能在后续会话加载，Agent 会如实说明；这不代替桌宠创建结果，也不代表可以擅自重启客户端。

## 使用

安装完成后，可以直接对 Kimi 说：

- 安装安燃桌宠
- 检查安燃桌宠的安装状态
- 恢复安燃的交互页面

单击、双击、连续点击和左右拖拽会触发对应动作；Kimi 执行任务时，安燃会根据实际任务状态切换表现。

## 边界

- 本插件创建独立安燃实例，不替换、不修改用户已有原生桌宠。
- 不修改 Kimi 宿主程序包，不依赖原开发电脑的工作区或项目文件。
- 插件安装成功不等于真实桌面视觉与交互已验收。
- 当前公开候选已完成插件结构、资源、安装脚本和离线包校验；第二台 Mac 的干净安装、真实交互和重启恢复仍需单独验收。
