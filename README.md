# 安燃

**住在桌面上的 Agent 小伙伴：看得见任务状态，也有自己的情绪和反应。**

安燃把原生桌宠、任务状态气泡和各 Agent 的连接配置放在同一个插件里。Kimi、WorkBuddy、vBuddy、千问和豆包共用同一份角色素材与原生运行器，不需要另装第二个 MCP 产品，也不需要手动解压运行器。

当前候选版本：**0.2.8**。支持 Apple Silicon Mac。

## 你能看到什么

- **会回应你的动作**：单击跳跃、双击施法，连续点击会触发升级反应，左右拖动切换动作。
- **眼睛会跟着你走**：在具备独立眼部数据的状态中追踪指针；点击、移动和任务状态切换时保留参考动作的表现。
- **任务状态一眼可见**：任务中、完成、等待确认和错误都有对应卡片与图标；多条任务可以计数、叠放和展开。
- **气泡可以直接操作**：叠放时先展开；运行中图标或整卡可打开所属 Agent，终态图标收起对应卡片。桌宠右下角提供折叠按钮。
- **跟着宿主来，也跟着宿主走**：Agent 连接时显示安燃，宿主退出时关闭；任务结束不会把桌宠一并关掉。

> 当前 WorkBuddy 连接能力只能打开宿主应用，不能定位到具体会话、代替你回复或取消任务。

## 在 Kimi 中使用

安装并启用“安燃”插件后，在对话中发送：

> 安装安燃

Kimi 会复用已有正式实例；确认不存在时才创建原生 DIY 桌宠并发布交互页面。插件详情页的“使用”按钮本身不会创建桌宠。

## 连接到其他 Agent

直接对已经装有安燃插件的 Agent 说：

> 把安燃连接到 WorkBuddy

也可以换成 vBuddy、千问或豆包。统一入口为：

```sh
skills/anran-pet/scripts/install_anran.py connect --host <宿主>
```

安装入口会把运行器和资源放入安燃自己的稳定目录，检查版本与哈希后切换 `current`。宿主只引用稳定安装目录，上一代保留用于回滚；移动源插件目录不会影响已安装运行器。

- **WorkBuddy**：使用 `--apply` 更新官方 MCP 数据文件和用户 hooks，保留无关连接器与配置。
- **vBuddy、千问、豆包**：通过对应宿主的官方连接器界面保存统一入口生成的配置。
- **其他 Agent 无需安装 Kimi**：运行器独立工作，Kimi 插件“更新”也不是其他宿主升级的前置步骤。

## 从 GitHub 安装

把仓库链接发给 Kimi，并说：

> 安装并启动这个仓库里的安燃

Agent 会连续完成插件导入、正式实例发现与复用或首次创建、页面发布。公开发布包通过指定 Git 标签获取，标签未推送前不能视为该版本已公开可装。

## 隐私与安全

- 核心功能离线运行，不索取 Agent 账号、模型密钥或远程控制权限。
- 气泡只显示经过截断的任务片段；完整提示词和工具正文不进入桌宠，也不写入任务事件正文日志。
- 只使用官方桌宠接口、官方连接器界面和 WorkBuddy 官方 MCP 数据文件，不修改宿主程序包。
- 安装或配置写入失败会明确报错并恢复旧配置与旧 `current`，不生成看似成功、实际不可用的配置。

## 发布与个人渠道

Kimi 个人插件可从插件详情页右上角的「✉️」入口申请发布到官方市场。WorkBuddy 按开放平台 Connector 规范提交；个人认证入口存在，但个人账号是否具备 Connector 发布资格，仍需在本人账号页面与审核结果中确认。

本仓库是公开安装与源代码入口。提交申请不等于审核通过，也不等于已经上架。
