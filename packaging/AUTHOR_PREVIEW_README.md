# 安燃 0.2.5｜作者内测包

本包用于验收安燃在另一台 Mac 上的真实安装与桌面体验。代码、页面与随附安燃资产采用 Apache License 2.0；尚未提交官方插件市场，本包不是公开上架版本。运行器未签名、未公证，不绕过 macOS 保护。

## 安装前

- WorkBuddy 安燃不需要安装 Kimi。安装器会先把运行器和资源写入 `~/Library/Application Support/Anran/`，再更新 WorkBuddy 官方 MCP 配置和用户任务事件配置。
- 检测到 Kimi 时，安装器还会调用 Kimi 官方入口安装或更新安燃插件；没有 Kimi 时会明确跳过这一部分，不影响已经安装的 WorkBuddy 安燃。
- 目标 Mac 需要 Apple Silicon。macOS 13 与干净系统兼容性尚未验收。
- 不需要安装 `pet-plus`，不需要复制原电脑的工作区、项目文件或原生安燃实例。
- 完整解压本包，不要只双击压缩包内的安装器。

## 安装

1. 双击 `Install Anran.command`。如果 macOS 阻止打开，按住 Control 点按安装器，选择“打开”；系统仍阻止未签名运行器时停止并保留错误，不绕过保护。
2. WorkBuddy 安装回执保存为 `workbuddy-install-receipt.json`；检测到 Kimi 时另有 `kimi-plugin-install-receipt.json`。
3. 手动重开 WorkBuddy。安燃配置指向安燃自己的稳定目录，不再需要到 Kimi 点击插件“更新”。
4. 如果安装了 Kimi 插件且提示需要重启，手动重启 Kimi，再说一句：**安装安燃桌宠**。这一步才创建 Kimi 原生桌宠实例。

插件安装、配置写入和进程启动不等于桌面视觉与交互已经验收。

## WorkBuddy 真实验收清单

由用户本人逐项记录“通过／失败＋截图或屏幕录制”，未测写“未验收”。

| 验收项 | 通过标准 |
|---|---|
| 独立安装 | 没有 Kimi 时仍能安装运行器并写入 WorkBuddy 官方配置；源包移走后运行器仍能执行 |
| 常驻与退出 | WorkBuddy 开着并连接时安燃显示；任务结束或 stdio 断开不关闭；退出 WorkBuddy 后安燃关闭 |
| 手动关闭 | 右键可打开 WorkBuddy 或关闭桌宠；关闭后的表现符合预期 |
| 任务气泡 | 开始、任务中、完成、等待确认和错误使用同一套白底圆角卡片；完成时保留任务片段并显示“任务完成”，任务中持续显示，不提前消失 |
| 点击后移出 | 点击动作开始后，即使指针移出宠物区域也继续播放完整动作，不被切回默认状态 |
| 拖拽 | 左右拖动跟手，方向按每次实际位移更新；拖停再拖不丢状态，松手恢复，位置保存且不自动回中央 |
| 追视 | 鼠标移动时整眼连续跟随，离开、释放或取消后恢复自然，不频繁丢失追视 |
| 眼周渲染 | 实际尺寸与白、灰、黑及桌面背景下均无眼周矩形、错色、黑块或裁切 |
| 单击与双击 | 单击跳跃、双击施法及回到默认状态符合设计 |
| 连续点击 | 快速连击按设计升级反馈，托盘和角色显示正常 |
| 异常提示 | 安装失败、资源缺失或配置冲突时明确报错，旧配置和旧运行器仍可恢复 |

发现问题时记录 macOS 版本、WorkBuddy 版本、操作步骤、实际结果、截图／录屏和安装回执。

## 0.2.5 更新

- 任务开始、进行中、完成、等待确认与错误统一使用独立原生圆角卡片；完成卡片保留任务片段，任务中的卡片持续到任务结束，断连时清理该连接持有的任务气泡。
- 卡片只改变右侧状态图标表达完成、提示或错误，不再给整张卡片染色；位置随宠物移动并限制在屏幕可见范围，不扩大宠物点击区域。
- 点击动作开始后，指针移出只更新悬停和追视，不再切回默认状态中断动作。
- 按压与拖拽移出窗口后由本地事件接续，松手和取消可正常收尾；左右方向按每次实际指针位移更新，并增加 60 Hz 补采样，避免相对起点总位移造成反向拖动误判。
- 各宿主继续统一先安装到安燃自己的稳定目录；上一代保留用于失败回滚。Kimi 插件“更新”只更新 Kimi 自己的插件副本，不是 WorkBuddy 的前置步骤。
- 空任务状态的眼动、追视和眼周改善保留；完整任务状态、点击后移出和真实拖拽手感仍须在 WorkBuddy 逐项验收。
